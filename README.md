# PaweeBoo

Public site for the PaweeBoo iPhone app. Served by GitHub Pages from `main`.

- **Privacy policy:** https://randomxmove.github.io/PaweeBoo/ — the App Store
  Connect *Privacy Policy URL* field.
- **Support:** https://randomxmove.github.io/PaweeBoo/support/ — the App Store
  Connect *Support URL* field.

Both are single self-contained pages — `index.html` and `support/index.html`,
each with its own inline CSS, no external requests and no build step. Edit and
push to `main` to publish.

Both describe **PaweeBoo 1.0** (the Free band): on-device only, no account, no
purchases, iPhone only. When a release turns on iCloud sync, shared households
or purchases, update both pages before that version ships.
