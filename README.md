# PaweeBoo

Public site for the PaweeBoo iPhone app. Served by GitHub Pages from `main`.

- **Privacy policy:** https://randomxmove.github.io/PaweeBoo/ — this is the URL
  in the App Store Connect *Privacy Policy URL* field.

`index.html` is a single self-contained page: inline CSS, no external requests,
no build step. Edit it and push to `main` to publish.
